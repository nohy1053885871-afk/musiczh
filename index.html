拾音 · 网易云 NCM、酷狗 KGM 在线转 MP3 工具

拾音是一个免费的在线音乐格式转换工具，可以将网易云音乐 .ncm、酷狗音乐 .kgm 与 .vpr 等加密音乐文件，一键还原为 MP3 / FLAC / OGG 等通用格式。所有文件都在浏览器本地处理， 不会上传到任何服务器，永久免费，永无广告。

支持的音乐格式

  • 网易云音乐 .ncm（无损还原为 MP3 或 FLAC）
  • 酷狗音乐 .kgm 与 .vpr v2（无损还原）
  • FLAC / OGG 一键转 MP3（基于浏览器原生 AudioContext + lamejs）
  • 批量转换：单次最多 50 个文件，支持 ZIP 打包下载
  • 自动写入 ID3 标签与专辑封面

使用方式

  1. 把要转换的音乐文件拖到首页的上传区，或者点击选择文件。
  2. 等待几秒，浏览器会在本地完成解密。
  3. 点击下载按钮，得到可在任意播放器中播放的 MP3 / FLAC 文件。

常见问题

.ncm 文件是什么？为什么打不开？
.ncm 是网易云音乐客户端下载歌曲时使用的加密格式，仅能在网易云客户端内播放。用拾音解密后即可在任意播放器中正常播放。
使用拾音会上传我的音乐文件吗？
不会。拾音是纯前端工具，解密、转码全部在浏览器本地完成，文件不会上传到任何服务器。
转换后音质会下降吗？
.ncm / .kgm / .vpr 在客户端下载时本身就是 MP3 / FLAC 数据，拾音只做还原，音质与源文件完全一致。
支持哪些音乐格式？
当前支持网易云 .ncm、酷狗 .kgm / .vpr（v2），QQ 音乐、酷我音乐等格式正在开发中。
拾音支持手机端使用吗？
支持。桌面与移动端浏览器都可以直接使用。
