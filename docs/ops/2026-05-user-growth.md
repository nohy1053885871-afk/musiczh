## 1. Context（这份方案为什么存在）

- 流量来源单点依赖小红书 → 抗风险能力差（算法 / 限流 / 你停发 → 流量归零）
- 没有沉淀型流量渠道（SEO） → 投入产出无法复利
- 没有数据归因能力 → 「流量靠小红书」是体感，没数据验证（小红书图片露域名手输的方式天然没法 UTM）
- 这份文档把**战略**和**执行**分离 → 战略级判断写在这，执行细节按需展开

## 2. 工具站增长的认知前提

拾音是 **高意图、低频、长尾搜索流量驱动的工具站**：

- 用户旅程：「我有 NCM 文件 / KGM 文件」→ 搜索 → 落地 → 用完即走
- 不会有人天天访问，**不是内容产品 / 不是社交产品**
- 工具站长期数据规律：**60-80% 流量靠搜索引擎**，社交内容只是冷启动加速器

这个认知决定了所有动作的优先级 —— SEO 是必须做的长期主义，社交内容是短期加速。

## 3. 4 渠道结构 + 长期目标

| 渠道 | 性质 | 当前状态 | 长期占比目标 |
|---|---|---|---|
| **SEO（搜索）** | 慢热 + 复利 | 0 投入，0 落地页 | 50-70% |
| **内容矩阵** | 见效快 + 不复利 | 仅小红书，未矩阵化 | 20-30% |
| **站内分享 / 口碑** | 小投入立刻见效 | 没做 | 5-10% |
| **异业合作 / 博主** | 中等 ROI | 没做 | 5-10% |

## 4. 主战场：两条腿走

### 4.1 SEO 落地页

**做什么**：在 sleepno.cn 加 `/guide/<slug>` 路由系统，写 5-10 篇深度教程，让百度/Google 收录后引导搜索用户。

**为什么有效**：
- 现在 sleepno.cn 只有一个工具页，**没有任何文字内容能匹配关键词** → 百度/Google 不知道我们能解决什么问题
- 用户搜「ncm 转 mp3」时我们排不上，相当于自动放弃了一大块免费精准流量
- 一篇文章写完，**未来 3-5 年都在持续带流量**（复利效应）

**第一批关键词候选**（按搜索量 × 难度排序）：

1. ⭐ `ncm 转 mp3` — 百度月搜索量 1-3 万，竞争中等
2. `kgm 文件怎么打开` — 月搜索量 5000-1 万
3. `网易云加密音乐怎么转 mp3`
4. `网易云 ncm 文件格式详解`
5. `酷狗 kgm 解密`
6. `flac 转 mp3 怎么做`（顺带 flac 转码副功能）

**文章结构模板**（800-1500 字）：

```
标题：<关键词> + 场景词 + 2026 完整教程

1. 什么是 <格式>？（200 字科普）
2. 为什么播放器打不开？（200 字技术解释）
3. 怎么转 / 怎么打开？（300 字，列 2-3 种方案，对比）
4. 用拾音的步骤（配 3-5 张截图）
5. 常见 Q&A（安全吗？批量行不行？支持哪些格式？）
6. CTA：立即试用 → sleepno.cn 首页大按钮
```

**预期效果**：
- 部署后 1-2 周被百度收录
- 进百度前 10 → 每篇月稳定带 200-500 访问
- 第一批 5 篇 = 月稳定 1000-2500 增量访问，长期复利

**投入预估**：
- 主站路由改造：~半天代码（Claude 做）
- 每篇文章：1-2h 写作 + 3-5 张截图（项目主写方向，Claude 起稿）
- 第一批 5 篇：一周搞定

### 4.2 内容矩阵化（小红书一鱼多吃）

**做什么**：以小红书为主战场，同步把内容改写后投到知乎 / B站 / 贴吧。**重点关注知乎** —— 知乎答案在百度权重极高，等于免费 SEO。

**矩阵分工**：

| 平台 | 内容形态 | 优先级 | 备注 |
|---|---|---|---|
| 小红书 | 图文笔记（图片露域名） | ⭐⭐⭐ 主战场 | 当前唯一渠道，继续做 |
| 知乎 | 答题为主，专栏为辅 | ⭐⭐⭐ 强烈推荐补齐 | 百度收录权重高，等于免费 SEO |
| B站 | 专栏 + 简短视频 | ⭐⭐ | 视频成本高，先做专栏 |
| 贴吧（音乐吧、网易云音乐吧） | 帖子 + 回复 | ⭐⭐ | 容易被删，需小心 |
| 抖音 | 短视频 | ⭐ 延后 | 视频制作成本太高，资源有限不做 |

**3 个固定内容栏目**（建议长期输出）：

1. **教程类**：「教你 3 步把 NCM 转 MP3」/「KGM 文件怎么打开」
2. **避坑类**：「别再用 XXX 在线转换器，它会上传你的文件」/「这 3 个工具不安全」
3. **场景类**：「想把 KTV 唱歌伴奏导出来 K 歌？」/「网易云会员歌曲想离线听？」

**节奏建议**：
- 每周 2-3 篇小红书
- 每条小红书发完后 24h 内改写投到知乎（标题加 SEO 关键词，正文加深一点技术内容）
- B站 / 贴吧每周 1 篇

### 4.3 站内分享 / 口碑（顺手做，小成本高 ROI）

**做什么**：用户用完产品后自然引导分享。

- 下载完成后弹「分享给朋友」按钮（复制带品牌的链接 / 文案）
- ZIP 包内塞 `readme.txt` 含品牌词 + 域名 + 一句话推荐语
- Footer 加「觉得好用 → 推荐给朋友」按钮

**投入预估**：4-6h 代码

## 5. 归因方案（折中版）

⚠️ **重要约束**：小红书图片露域名 + 用户手输 → 没法带 UTM 参数。所以**放弃 URL 级精确归因**，改用 3 个间接归因组合：

| 手段 | 作用 | 投入 | 当前决策 |
|---|---|---|---|
| 站内首次访问问卷（「你怎么知道拾音」浮卡） | 最准的来源归因 | 3h 代码 | 🔴 暂缓 |
| 百度站长 / Google Search Console | 品牌词「拾音」搜索量监测（小红书发力 → 品牌词搜索量上涨 = 滞后归因） | 30min 注册 | 🟡 待项目主做 |
| 小红书后台数据 | 笔记曝光 / 互动率前置归因 | 0 投入 | 🟢 持续观察 |
| `classifyChannel` 补全小红书域名识别 | 万一未来 referrer 能传过来就能识别 | 1h 代码 | 🔴 暂缓 |
| UA 识别 App 内置浏览器 | 把小红书 App / 微信 App 流量从「直接访问」分出来 | 1h 代码 | 🔴 暂缓 |

**用户当前决策**：归因方案先全部暂缓不做。等 SEO/内容矩阵跑 1-2 个月后再看是否需要。

## 6. 暂缓 / 永久放弃事项

**暂缓**（重启条件：SEO/内容矩阵跑 1-2 个月后流量结构仍说不清）：

- `classifyChannel` 加小红书域名识别
- UA 识别 App 内置浏览器
- 来源问卷浮卡

**永久放弃**：

- UTM 参数埋点（确认对小红书无效 —— 图片露域名 + 用户手输长 URL 不现实）
