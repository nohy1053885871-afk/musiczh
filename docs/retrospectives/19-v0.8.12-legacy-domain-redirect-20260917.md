## 本次故障与根因

1. 本地后台曾在 API/Vite 进程退出后保留旧页面，点击开关显示保存失败。根因是浏览器内存中的 SPA 仍可见，但 `127.0.0.1:8787` 已无监听；重启隔离 API 后，读写与恢复均为 200，不是开关代码或 SQLite 故障。
2. 合并到 `main` 会自动触发阿里云前端，而 API 按安全策略必须手动 dispatch，因此本次前端先完成、API 随后完成。开关默认关闭且后台加载失败会禁用操作，未造成错误跳转，但后续跨端版本应在合并前明确设计 API 先行发布窗口，避免短暂能力不匹配。
3. 本地生产 smoke 脚本首次没有加载 GitHub Actions 使用的 SSH key，认证失败且没有触碰服务器；改用临时 SSH agent 后同一脚本通过。
4. 生产浏览器自动验收再次超时。HTTP、清单、资源和 bundle 证据有效，但不能替代生产真实交互。
