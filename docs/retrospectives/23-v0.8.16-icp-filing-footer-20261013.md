- `sleepno.cn` 普通页面当前由既有开关 307 到主域，因此访客会在跳转后的主域页脚看到备案号；阿里云静态目录本身也已同步包含备案组件，关闭跳转后无需再次发布。

## 本次故障与根因

1. 本地 `git fetch` 到 GitHub HTTPS 端点连续超时，但 GitHub API 可用。发布分支从远端 `main` 最新 tree 创建，合并前核对为 ahead 1、behind 0 且仅含 5 个目标文件，避免把本地旧历史带入 PR。
2. 阿里云发布先成功，Cloudflare Wrangler 前两次在访问官方 API 时连接超时，形成短暂的双端版本不一致；期间明确保持“发布未完成”状态。
3. 多个公共 DNS 均返回同一组 Cloudflare 官方地址，但本机到这些地址的直连 TCP/TLS 不可达。最终通过现有阿里云 SSH 建立临时转发，在 Cloudflare 官方主机名、证书链和 TLS 校验全部通过后发布；没有修改系统 DNS、关闭证书校验或把 OAuth 凭据上传到第三方。发布后立即关闭并清理临时转发。
