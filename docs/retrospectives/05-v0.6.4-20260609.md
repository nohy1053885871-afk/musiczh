**性能分析（v0.6.4 首读，仅供定性）**

> 覆盖率：decrypt_ms 非空 21,053/36,966（57%）、transcode_ms 非空 3,587/7,362（49%）—— 与 0.6.4 铺开 59% 同步，旧版客户端无此字段拉低，会随版本继续逼近 100%。本期数字按**方向性**看，绝对值待覆盖率上来再定基线。

| 指标 | avg（ratio-of-sums） | P50 | P95 | 每 MB |
|---|---|---|---|---|
| 解密 | 2,154 ms | 398 ms | 4,654 ms | 113.7 ms/MB |
| 转码 | **111,873 ms（≈112s）** | **78,662 ms（≈79s）** | **336,896 ms（≈5.6min）** | 1,975 ms/MB |
| 端到端/文件 | — | 425 ms | 140,890 ms（≈2.3min） | — |

- 每 MB 转码（1,975）≈ 每 MB 解密（113.7）的 **17×**，符合预期（解密=XOR/RC4，转码=PCM 全解码 + LAME VBR 编码）
- 每 MB 解密分来源：NCM 115.1 > KGM 59 > QMC 28.2（n 仅 139，低置信）—— **KGM 查表 XOR 比 NCM 的 AES+RC4 快**，可解释 ✓
- 各档 P95 远 > P50（端到端 P95/P50 ≈ 330×），右偏明显 → 数据真实。端到端双峰：多数人只解 NCM 秒级完成（P50 0.4s），少数走转码拖到分钟级（P95 2.3min）

**封面命中率 has_cover（decrypt_done 按来源）**：NCM 33,308/34,642 = **96.1%** ✓；QMC 0/1,256 = **0%**；KGM 74/1,068 = **6.9%**。QMC/KGM 低是**平台特性**（QQ/酷狗封面靠在线 API 查 song_id，文件本身无 PICTURE block，复盘 #3 教训 #4 已字节级证实），非提取 bug。
