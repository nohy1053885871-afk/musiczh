## 数据快照与问题边界

- 截图中的 `.kgg.flac` 文件被识别为 `FLAC`，失败行仍显示旧文案“酷狗新版加密格式（v4），本工具暂不支持”，且提供了对同一文件无效的“重试”。
- 当前错误码 `KGM_V4_UNSUPPORTED` 是历史名称；真实边界是文件本身没有当前解密器可用的 Key。为避免扩大本次变更，不重命名错误码和历史数据。
- 电脑客户端重下是面向普通用户的下一步，但不保证所有电脑客户端下载物都密钥内置；因此使用“这可能是”而不是确定性断言。
- 本版不实现 Key 提取、不新增弹窗、不新增事件、不改 API 或数据库。

## 实现与本地验收

- 酷狗直接拦截和 KGM/VPR 解密后 magic 校验失败两条路径统一为：“这可能是酷狗新版加密格式，暂时无法转换。请在电脑客户端重新下载后上传并解密”。
- 失败文案取消单行截断并允许换行；外部 Key 类错误隐藏无效重试。
- 文件来源徽章优先识别 `.kgg/.kgm/.vpr` 容器，截图同类 `.kgg.flac` 文件显示 `KGG`。
- 支持矩阵、FAQ/JSON-LD、后台错误码标签、项目说明和埋点规范同步同一边界。
