## 数据快照与实现边界

- 根因是浮层的 `mouseenter` / `focus` 绑定在占满整行的块级容器上，容器虽只显示居中的短文案，但整行空白都是命中区，因此鼠标离文案较远也会打开。
- 外层容器改为随内容收缩的 `inline-flex`；打开行为只绑定到入口按钮，只有文案本身被悬浮或聚焦时才触发。
- `mouseleave` / `blur` 仍由同时包住入口和浮层的外层容器处理，鼠标从文案移动到图片时不会误关；桌面点击、键盘、触屏底部弹层和既有埋点事件名均未改变。
- 本版只改用户端组件与版本号。运营后台、API、数据库结构、配置内容和统计口径均未改动。

## 本次故障与根因

1. 原热区问题不是图片或定位偏移，而是事件绑定层级错误：视觉入口只有按钮宽度，监听元素却是整行块级容器。
2. 初始 PR #90 暴露本地分支与远端 `main` ancestry 不一致。该 PR 未合并并已关闭；随后从远端 `main` 的 tree 创建干净分支，PR #91 的文件范围和最终 tree 均经过核对。
3. Cloudflare 直接发布首次遇到本机 DNS 将 `api.cloudflare.com` 解析到非官方、自签名证书地址。经 1.1.1.1、8.8.8.8、9.9.9.9 一致解析和官方 TLS 校验后，仅对该 Wrangler 进程注入官方地址完成发布；未修改系统 DNS，也未关闭 TLS 校验。
