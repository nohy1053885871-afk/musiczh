首次本地验收后，项目主明确取消按钮与对应链接配置。最终实现已同步删除跳转接口和点击指标，不保留未使用的半套链路。

## 数据快照与实现边界

- 403 受限页保留原有访问限制说明；运营文案为空时不挂载辅助提示区，接口异常时也只回退基础文案。
- 运营后台配置中心只保存 200 字以内纯文本，不提供按钮或链接配置。文案可自行包含小红书账号或说明。
- 辅助文案以 13px、`#918A84` 展示，视觉层级低于基础 403 说明。
- 曝光写入独立 `site_access_events`，不伪造 `visitor_id/session_id`，不进入主站 PV、UV、v0.8.8 双域名 traffic、设备分布、访客日志或 overview rollup。
- 后台首页最后一张卡只展示受限页曝光 PV 与去重 IP；旧 API 缺字段时显示部署告警，不伪装为零数据。
