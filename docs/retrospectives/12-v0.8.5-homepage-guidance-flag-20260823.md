## 数据快照与问题边界

- 首页的平台支持短语、格式总览入口和 QQ 指引入口此前只能随主站发版调整，运营侧无法临时隐藏。
- `feature_flags` 表和后台配置中心已经预留，但没有存取模块、API 或真实配置控件。
- 本次只控制截图红框内容；容量限制、下载帮助、QQ 自动唤起、失败行指引和弹窗能力保持原样。
- 配置默认开启，公开接口故障或响应非法时主站回退为显示，避免 API 故障扩大成用户端功能缺失。

## 实现与本地验收

- API 增加单一白名单配置的公开读取与管理员 GET/PUT，写入严格限定为 boolean，并以单条 upsert 保证最后写入生效。
- 后台配置中心具备加载失败重试、保存中锁定、成功更新时间与失败保持原值。
- 主站用 `null / true / false` 三态加载配置；读取中不挂载受控入口，关闭时容量限制和下载帮助自动清理前导分隔符。
- 受控组件不挂载时，其既有入口曝光事件自然停止；没有新增事件名。
