# v0.8.5 首页指引运营开关实施计划

## 一、目标与边界

1. 复用 `feature_flags` 表增加 `homepage_guidance_visible`，默认开启。
2. 关闭时只隐藏首页平台支持短语、格式总览入口和 QQ 指引入口。
3. 单文件/队列限制、下载帮助、QQ 自动指引、失败行指引及现有弹窗保持不变。
4. 配置在新打开或刷新的主站页面生效，不增加轮询或实时推送。
5. 配置接口失败、响应非法或 3 秒超时时回退为显示。

## 二、三端改动

1. API
   - 初始化 feature flag 默认值，增加强类型存取模块。
   - 公开 `GET /api/config`，只返回允许公开的首页指引布尔值。
   - 增加鉴权的 GET/PUT 管理接口，严格校验布尔写入并返回更新时间。
2. 运营后台
   - 将配置中心占位页替换为“首页格式与 QQ 指引”开关。
   - 覆盖加载、重试、保存中、保存成功和保存失败状态。
3. 主站
   - 首次加载配置时暂不挂载受控内容，完成后按开关渲染。
   - 拆分上传区副文案和入口分隔符，关闭时不留下孤立圆点。
   - 保留下载帮助、QQ 自动唤起和失败行入口。

## 三、接口与存储

- 存储键：`homepage_guidance_visible`，值只写 `true` / `false`。
- `GET /api/config` → `{ homepageGuidanceVisible: boolean }`，`Cache-Control: no-store`。
- `GET /api/admin/feature-flags/homepage-guidance` → `{ enabled, updatedAt }`。
- `PUT /api/admin/feature-flags/homepage-guidance`，body `{ enabled: boolean }`。
- 缺行、非法历史值和主站读取异常统一回退为开启；后台读取异常不允许提交。
